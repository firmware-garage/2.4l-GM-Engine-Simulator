# 2.4l-GM-Engine-Simulator
Simulator of a running 2.4l Ecotec engine

 - Simulates signals from a crankshaft position sensor and two camshaft position sensors
 - Simulates APP signal with proper tracking
 - Approximates MAF and MAP signals
